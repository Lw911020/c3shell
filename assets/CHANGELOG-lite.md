# C3 控制台 · 版本介绍

**这是什么**：给 comma 三/五（C3/C3X）辅助驾驶设备用的**手机端控制台** —— 手机或平板装一个 APK，
连上设备就能远程看状态、调参数、采曲线、投屏、听语音播报。
**特点**：服务与页面都内置在 APP 里（不用电脑、不用 node、不用 root）；车机模式与手机/平板模式一套 UI 自动切换 ✓

> 这里只写「新增功能」和「功能调整」—— 说明这套软件现在能做什么、最近改进了什么 ✓

## v3.00 系列（2026-09-24）

**新增**
- **文件操作改成「长按 / 右键」菜单**：文件行不再堆一排按钮 —— 长按文件名（或右键）弹出「编辑 / 下载到本机 / 上传到设备 / 复制 / 剪切 / 改名 / 删除」，按设备或本机、文件或目录自动变项
- **文件页能复制 / 移动，还能看手机自己的文件**：工具栏新增「本机储存 / 切回设备」；每个文件有「复制 / 剪切」，工具栏「粘贴」——**设备内、设备⇄本机、本机内**四个方向都能走；设备文件可一键「下载到本机」（SFTP 流式），本机文件可「上传到设备」
- **投屏页也能熄/亮 C3 屏幕**：投屏按钮行新增「C3 熄屏 / C3 亮屏」，旁边显示 `C3 屏：亮/熄`；熄屏只关背光，**投屏与采集照常**（与悬浮窗右上角那个键同一套逻辑）
- **体验版转正更方便**：体验期结束后，获取正式授权并在 APP 内激活即可继续使用，**不用重新装包** ✓
- **体验版（可选构建）**：**3 天倒计时（72 小时）**，右上角常驻剩余时间，最后 24 小时每天提醒一次，到期弹窗提示；正式版不受影响
- **系统版本识别**：连上设备先认系统 —— 顶部显示 `CarrotPilot 0.9.9` / `SunnyPilot 2025.002` 等，并按该系统能力开关功能（不支持的自动置灰或提示）
- **投屏「一键安装投屏能力」**：换系统后设备端钩子会丢，投屏页点一下即可（编译 → 注入 → 重启 → 自检）；投屏卡片常驻显示「投屏能力：已就绪 ✓」
- **参数中文备注**：参数表 100% 有中文名 + 说明（设备端自带说明优先，内置词库 645 条兜底，覆盖 CP / SunnyPilot 2025 / SunnyPilot 0.9.8）
- **参数分层显示**：默认只看「常用可调」；动作型（危险，写入即执行）单独成组；内部状态一键展开
- **文件页改名 / 删除 / 新建文件夹**（原来只有列目录）
- **投屏触控按设备记忆**：方向与「启用反控」状态每台设备各记一份，换系统不用重新试
- **问题反馈可直接发回作者**（自动附上最近日志与当前界面截图）；「激活 / 授权」里能看到本机设备号与授权状态
- **参数设置提升为一级菜单**；**软件设置的二级菜单移到侧边栏**
- **赞赏提醒**：每 5 次打开「关于」页提示一次；可直接点「我已赞赏」回填金额（> 20）
- **诊断台与主控台共用同一套连接**（后端默认主机为唯一真源，双向同步）

**调整**
- **重启类操作新增风险提示**：装投屏钩子 / 重启设备 / 重启 openpilot / 重启 card 之前会提醒「车辆通电时重启可能锁 LKAS 故障，需熄火重启车辆才能恢复」—— 建议熄火后再操作
- **换系统后不用再干等**：「投屏能力」那行不再卡在「检查中…」—— 打开页面就主动探测、失败自动重试并给「重试」按钮；钩子没装时不再空连画面（顺带治住几十条僵尸连接）
- **赞赏弹窗更省事**：填的金额大于 20 就先把弹窗关掉、上报转后台，只用一条轻提示 ✓
- **界面显示模式默认「自动」**：宽度 ≥900dp 自动用车机布局（左栏菜单），否则手机/平板布局；界面设置里仍可一键改（会记住）
- **离线时不再卡界面**：设备不在线时，SSH 请求先做 700ms 预探测 + 8 秒负缓存 + 同一时刻只连一次（8 秒超时 → **4 毫秒**返回）；终端相关轮询只在终端页跑 → 切页/滚动顺滑（Janky 5.6% → 0.8%），点菜单不再没反应
- **安全加固**：代码混淆 + 内置资源加密（换签名重打包解不开）+ 关闭 WebView 远程调试 + 反调试提示
- **投屏延迟大降**：修掉「撞上半截帧白等 100ms」（出帧 6.4 → 19.4 fps）；默认改成**客户端拉最新帧**（延迟不累积）；默认 **1024×600 / 15fps**；「低 / 中 / 高」三档即时可切
- **终端输入条提速**：长命令输出**变成流式**（429ms → 3ms）
- **投屏钩子跨系统**：同时兼容两种调用方式；没有 OpenCV 时自动改用 PIL 编码
- **悬浮窗**：默认尺寸翻倍；修好「换系统后没画面」
- **特色介绍**：入口调整为「投屏与反控」
- **运维页卡片**改为页签（通用脚本 / 更新包 / 刷机引导）；**浮窗**状态栏与缩放把手平时隐藏
- **熄屏 / 亮屏**：读真实亮度状态，备份不再写入 0

## v2.119 系列（2026-09-23 ~ 09-24）

**新增**
- **投屏**：车机实时画面 + 悬浮小窗；触控反控；WebView 失焦自动重连
- **AI 分析**：扫描行车接管日志（qlog）出结论；报告可下载或交大数据平台；问 AI 自动带上设备与参数数据
- **参数**：注册表 + 当前值 + 厂商说明；批量下发带风险提示；档案 A–H / Z 可回滚
- **诊断台**：曲线采样与拖动排序、横向诊断、路线重放、主机与主控台同步
- **语音**：辅助驾驶状态变化播报；提示词 / 音色 / 语速可自定义；本机 TTS 自检
- **授权**：激活后解锁全部功能（一机一码）+ 功能开关（AI 分析 / 路线扫描 / 问题反馈）
