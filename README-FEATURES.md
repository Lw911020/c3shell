# C3 控制台 · 特色介绍

手机 / 平板 / 车机通用的 openpilot（comma C3）控制台。连上设备即用，参数、曲线、AI 分析、语音提示一站搞定。

## 🗂 参数保存（档案 A–H/Z）
- 整套参数**一键存成档案**，随时对比、应用、回滚
- 与**厂商默认值逐项对比**：当前值 / 默认值 / 偏离幅度 / 中文含义与影响
- 档案之间可比、档案与设备现状可比；支持 **CSV 导出 / 导入写入**
- 可一键把「当前整套参数」存为档案（与 AI 分析联动）

## 📈 转向诊断曲线
- 14 张**实时曲线**：车道/曲率/横向加速度/转向扭矩/前车/速度/模型序列…
- 支持采样、时间窗、快照 CSV
- **分析本次采样**：转向饱和率、横向加速度跟随误差、曲率跟随误差、车道线概率、激活占比与切换次数

## 🤖 AI 分析
- **一键综合分析**：设备现状 + 参数差异 + **路线 qlog 分诊** + 采样报告 → 综合结论
- **路线 qlog 分诊**：真读 qlog，给出每条路线的段数、接管率、最高车速、**接管次数与时刻**、主导类型（驻车/手动/全程接管/有干预）
- 只统计「被 openpilot 接管」的路线，后台扫描带**真实进度条与 ETA**，切页面不中断
- **问 AI**：带上真实设备数据提问，解答车主疑问（如"高速弯道为什么降速慢"）

## 🔊 语音提示
- 辅助驾驶状态变化时**车机语音播报**（本机 TTS）
- 提示词可自定义，音色 / 语速 / 输出通道可调，自带 TTS 自检

## 📡 设备查找与连接
- **雷达扫描**局域网里的 C3 设备，点一下替换 IP 并自动连接
- 连接失败自动跳转 SSH 控制台（主机页）修改端口/用户/密钥
- **内置 8 把密钥**，免配置即连；连接提示与报错**全中文**

## 🖥 SSH 控制台 · 终端
- 快捷指令：重启设备 / 重启 card / 重启 openpilot / 安装 / 返回
- 文件浏览与传输、实时监控、录制数据一览
- 终端输入条跟随主题，车机模式下与侧栏一体化

## 🎛 界面与体验
- 主题（含四季配色）/ 字号与密度 / 显示模式（手机 · 平板 · 车机 · **自动**）
- **车机模式**：左侧栏 + 一体化布局，适配车机大屏
- **低版本适配**：支持 Android 4.4（API 19）起的车机；老系统自动进入**低配模式**（关动画、减渲染）
- 卡片上下移动按钮已移除，界面更干净

## 🛠 问题反馈 · 🔑 卡密激活
- **问题反馈**：一键打包「描述 + 最近日志 + 界面截图」，可分享
- **卡密激活**：一码一机设备绑定、到期时间、功能开关；**在线统计可关闭**，只上报匿名设备信息
